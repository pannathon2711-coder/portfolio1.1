## 🎨 สไตล์และองค์ประกอบการออกแบบ (Design Specifications)

- **Color Palette (โทนสีหลัก):**
  - สีแดงนวล / Soft Crimson: `#f43f5e`, `#fb7185`, `#be123c`
  - สีนีออนเรืองแสง & Cyber Glow: `rgba(244, 63, 94, 0.45)`
  - แบ็กกราวด์ Cyber Dark: `#07080c`, `#0c0e14`
- **Template Style:**
  - Cyber/Tech Dark Mode (กลิ่นอายไซเบอร์ สีนีออนเรืองแสง เส้นกริด HUD สแกนไลน์ มุมกล่องล้ำยุค)
  - Interactive Canvas แสดงเครือข่ายเส้นใยและโหนดจำลองโครงข่าย ICT
  - ระบบเสียงตอบสนองด้วย Web Audio API (Synthesizer Beeps) เปิด-ปิดได้
- **Nav Layout:**
  - เมนูแนวตั้งอยู่ฝั่งซ้ายมือ (Sticky Left Vertical Sidebar) เต็มความสูงหน้าจอ
  - รองรับหน้าจอมือถือด้วยปุ่มเมนู Hamburger และ Drawer Overlay สไลด์เข้า-ออกอย่างลื่นไหล
- **Multi-Language Support (ปุ่มสลับภาษา):**
  - ปุ่มสลับภาษา TH / EN บริเวณมุมบนของแถบเมนูและแถบควบคุมบนมือถือ
  - สลับข้อความทั้ง 6 ส่วน พร้อม Placeholder และตัวเลือกภาษาทันทีโดยไม่ต้องโหลดหน้าเว็บใหม่
